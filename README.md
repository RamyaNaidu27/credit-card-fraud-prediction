# 💳 Credit Card Fraud Detection using Deep Learning, Graph Neural Networks & Autoencoders

An intelligent banking fraud detection system that uses Machine Learning and Deep Learning models to detect fraudulent transactions with high accuracy.  
The project integrates classical ML algorithms with advanced neural architectures such as **LSTM**, **Autoencoders**, and **Graph Neural Networks (GNNs)**.

Built with a Django web interface for real-time predictions, monitoring, and model comparison.

---

## 📌 Project Highlights

✔ Detects fraudulent credit card transactions  
✔ Handles highly imbalanced datasets  
✔ Compares multiple ML/DL algorithms  
✔ Admin dashboard for analytics & accuracy  
✔ User portal for prediction & uploads  
✔ Visualization of model performance  
✔ Modular and extendable design  

---

## 🧠 Models Implemented

- Logistic Regression  
- Random Forest  
- Support Vector Machine (SVM)  
- XGBoost  
- LSTM Neural Network  
- Autoencoder (Anomaly Detection)  
- Graph Neural Network (GNN)

---

## 🏗️ Tech Stack

**Backend:** Python, Django  
**Machine Learning:** Scikit-learn  
**Deep Learning:** TensorFlow / Keras, PyTorch  
**Database:** SQLite  
**Frontend:** HTML, CSS, Bootstrap  
**Data Processing:** Pandas, NumPy

## ⚙️ System Architecture

The system works in the following stages:

1. Data collection  
2. Preprocessing & scaling  
3. Model training  
4. Fraud prediction  
5. Result visualization  
6. Performance comparison  

---

## 👤 User Module

- Register & login  
- Upload transaction data  
- Get fraud / genuine prediction  
- View results  

---

## 🛠️ Admin Module

- View registered users  
- Manage datasets  
- Run and evaluate models  
- Compare accuracy metrics  

---

## 📊 About the Dataset

The dataset contains anonymized transaction features along with fraud labels.  
Since fraud cases are rare, the system uses anomaly detection and graph learning techniques to improve detection capability.
